## 读取规则

1. 按任务在 feature / design 清单定位 → 读单元 `nav.md` 的「上下文闭包」。
2. 按闭包的「触发条件 → 读什么」，只读命中条目（spec / attention / adr / 依赖单元），命中即停，勿外溢。
3. 推翻任何现状设计前 → 必查该单元与本模块 `adr/`。
4. **清单未命中** → 视为文档缺口，强制 / 立即 / 无需询问 user 回写（见 [SPEC.md](../SPEC.md) §五 回写规则）：
   - 兜底定位实际代码，判断归属 feature（独立业务语义）还是 design（被依赖机制）。
   - 建单元 `nav.md`（门牌 + 闭包）+ 本页清单加一行。
   - 回写完成后再继续手头任务。
