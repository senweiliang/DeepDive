Capabilities

Everything you need,
nothing you don't

DeepDive ships with the essentials. No plugin marketplace, no yak-shaving — just tools that ship code.

⚡

Streaming Reasoning

Watch DeepSeek think in real-time. Reasoning blocks render as they stream — collapsible, searchable, never in your way.

🔧

Tool Execution Loop

Read, write, edit files. Glob and grep your codebase. Run shell commands. Web search via Tavily. The agent uses your real tools.

🛡️

Permission Gating

Plan mode (read-only), Agent mode (confirm writes), YOLO mode (full auto). You control what the agent can touch — every time.

🧠

Context Window Management

Auto-compaction at 80% window usage. Prefix-cache-friendly prompt ordering. DeepSeek's 1M token window, used wisely.

💾

Session Persistence

JSONL append-only storage. Resume interrupted sessions with --resume. Your conversation survives crashes, reboots, and lunch.

📊

Cost Tracking

Real-time token counts, cache hit/miss breakdowns, per-turn and per-session cost. Know exactly what each request costs — in yen or dollars.

Get Started

Three steps to your
terminal copilot

STEP 01

Install

One command. Bring your own DEEPSEEK_API_KEY. Works with npm, pnpm, or yarn.

STEP 02

Chat

Describe what you need. The agent explores your codebase, plans its approach, and shows you the reasoning.

STEP 03

Ship

Approve the changes. Files are written, tests pass, and you move on. All inside the terminal — where you already work.

Install

One command and you're in

$ npm install -g @mrbone11/deepdive

Requires Node.js ≥ 20 and a DeepSeek API key
